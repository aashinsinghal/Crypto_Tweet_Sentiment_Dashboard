# Crypto_Tweet_Sentiment_Dashboard
Cleaning data of tweets relating to crypto to be visualized in Tableau

Tableau Dashboard: https://public.tableau.com/app/profile/aashin.singhal/viz/CryptoTweetsSentimentDashboard/CryptoTweetsSentimentDashboard

After downloading a dataset of over 75000 tweets from Kaggle, the attached scripts clean and trim the data so that the tweet text can be readable and certain datapoints such as location can be understood by Tableau. I used TextBlob to determine the sentiment polarity of each tweet after it had been cleaned.

Using these sentiment polarity figures, I created several key visualizations in Tableau including average sentiment by region, a word cloud of the most frequent words used in the tweets analyzed, and a sentiment polarity bar graph indicating the volume of tweets at each sentiment.
